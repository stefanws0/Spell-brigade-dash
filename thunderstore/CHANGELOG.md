# Changelog

## 0.5.1

- New icon: the Dash card's art.
- New package name: **Dash** (0.5.0 was "SpellBrigadeDash"). Uninstall the old one if you have it.
- The source is on GitHub now: https://github.com/stefanws0/Spell-brigade-dash

## 0.5.0

First release.

- A short Space / LB dash with i-frames, a charge bar under your wizard, and violet afterimages, sparkles and streaks
  together with the game's own teleport burst and speed lines.
- Runs start without the dash: find the **Dash** card (Epic) in the level-up shop. Upgrades: **+1 Dash Charge**,
  **Quick Recovery**, **Long Stride**, **Blazing Dash** (a fire trail that burns enemies like the Trail spell) and
  **Ethereal Step** (no HP cost).
- Your dash stats show in the game's stats list.
- Co-op hasn't been tested yet.
